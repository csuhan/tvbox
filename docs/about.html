FAQ

常见问题

首页空白 / 提示没有可用接口？▼
接口地址失效或网络不通。进入「我的 → 设置与数据源」，换一个内置推荐接口，或添加新的 TVBox 接口地址。
某些站点显示"暂不支持"？▼
该站点是 type 3 爬虫源（需要 Spider JAR/JS 运行环境），手机版暂不支持。请在站点列表中切换其他站点使用。
播放失败怎么办？▼
依次尝试：切换剧集线路 → 切换站点 → 更换接口。部分地址有防盗链，App 已自动携带 UA/Referer 并支持嗅探解析，大多数情况可直接播放。
App 会收集我的数据吗？▼
不会。App 仅请求网络权限，无账号体系、无埋点统计，所有历史与收藏均存储在本机。
